# Dataset files

Download the three assigned MAT files from the [Kaggle dataset](https://www.kaggle.com/datasets/itshpark/data-driven-prediction-of-battery-cycle) and place them in this directory, or set ESS_DATA_DIR to their location.

Required files:

- 2017-05-12_batchdata_updated_struct_errorcorrect.mat (Batch 1)
- 2018-02-20_batchdata_updated_struct_errorcorrect.mat (Batch 2)
- 2018-04-12_batchdata_updated_struct_errorcorrect.mat (Batch 3, optional test)

The raw MAT files are not committed because of their size. Keep their filenames unchanged.
